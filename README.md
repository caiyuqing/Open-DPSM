# Open Dynamic Pupil Size Modeling (Open-DPSM) Toolbox

- [v1](https://github.com/caiyuqing/Open-DPSM/tree/master/v1): the original version 


- [v2](https://github.com/caiyuqing/Open-DPSM/tree/master/v2): Incorporated the features of circular map, regional weights and regularization.

- [v3](https://github.com/caiyuqing/Open-DPSM/tree/master/v3): Incorporated the feature of modeling multiple movies together. 

- [v4](https://github.com/caiyuqing/Open-DPSM/tree/master/v4): Predicting absolute pupil size for removing the influence of luminance under dynamic environments

- [Regional_weights_illustration](Regional_weights_illustration): An interactive illustration for the regional weights. 

See specific folders for more instructions!

Citations: 

General use and overview: Cai, Y., Strauch, C., Van der Stigchel, S., & Naber, M. (2023). Open-DPSM: An open-source toolkit for modeling pupil size changes to dynamic visual inputs. Behavior Research Methods. https://doi.org/10.3758/s13428-023-02292-1

For usages of regional weights, please cite: Cai, Y., Van der Stigchel, S., Ganama, J., Naber, M. and Strauch, C. (2025), Uncovering Distinct Drivers of Covert Attention in Complex Environments With Pupillometry. Psychophysiology, 62: e70036.
